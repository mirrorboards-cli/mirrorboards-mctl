# Mirrorboards MCTL

A powerful command-line interface tool for managing mirror.toml configuration files.

## Quick Installation

```bash
cargo install --git ssh://git@github.com/mirrorboards/mirrorboards-mctl.git --config net.git-fetch-with-cli=true
```

## Project Structure

This repository contains:

- **mctl**: The main command-line tool for managing mirror.toml configuration files
- **mirror-sdk**: The underlying SDK that powers the mctl tool
